# Unicode Fonts

Unicode Fonts converts the text you type into various Unicode styles.

## Usage

Open [the page](https://dazzywi.github.io/unicode-fonts/) and type in the box at the top. Every style updates as you type.
The search box filters styles by name.
Clicking a style's title or its star pins it above the others.
The Copy button puts that style on your clipboard.

## Shared links

Your text, pinned styles and search are stored in the URL, not in cookies or browser storage.
A reload or a shared link restores the same view, and an empty URL starts fresh.
